
# Phishing Email Detection Model

## Project Description
This project uses Machine Learning to identify phishing and legitimate emails.

## Objective
To classify email messages into two categories:
- Phishing
- Safe

## Technologies Used
- Python 3.14
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Algorithm
Logistic Regression

## Features
- Email text classification
- Suspicious keyword detection
- URL count extraction
- Email length analysis
- Accuracy evaluation
- Confusion Matrix visualization
- Custom email testing

## Dataset
The project uses a sample dataset containing 40 labelled email messages.

## How to Run

1. Install Python.
2. Install required libraries:

```bash
pip install pandas scikit-learn matplotlib seaborn
```

3. Run the project:

```bash
python main.py
```

## Model Evaluation
The initial sample test produced 100% accuracy on 6 test emails.

Note: This is a small demonstration dataset. The result does not represent real-world detection performance.
